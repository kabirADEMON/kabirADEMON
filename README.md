### Ce que je soigne

- **Des tests qui prouvent quelque chose** : base PostgreSQL réelle plutôt que simulée, parcours complets dans un navigateur, intégration continue sur GitHub Actions.
- **La sécurité dès le départ** : mots de passe hachés, limites anti-abus impossibles à contourner, en-têtes stricts, et un test qui rejoue chaque attaque.
- **Des données justes** : contraintes en base, montants et numéros de reçus qui ne peuvent pas être faux, numéros de téléphone béninois normalisés (8 ou 10 chiffres).
